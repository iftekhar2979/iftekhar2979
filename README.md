### 👨‍💻 About Me

I am a **Backend Engineer** focused on building resilient, scalable backend architectures, high-performance REST APIs, and microservices using **NestJS**, **Node.js**, and **TypeScript**. 

With a strong foundation in **Applied Mathematics (B.Sc.)**, I bring mathematical rigor to database query indexing, distributed caching, algorithmic optimization, and system design. My background spans:

- 📱 **Mobile Backend Ownership**: Sole backend developer for production applications live on the **Apple App Store** and **Google Play Store** ([Pet Attix](https://apps.apple.com/us/app/pet-attix/id6753793083)).
- 🏢 **Enterprise & IoT Systems**: Architected multi-tenant SaaS platforms on AWS integrated directly with **ZKTeco biometric IoT** hardware for automated employee attendance.
- ⚡ **Database & Performance Optimization**: Reduced query latency and bottlenecks by **15%** through indexing, query restructuring, and Redis caching.
- ☁️ **DevOps & Infrastructure**: Managed and supported **8+ production environments** and **10+ client systems** with automated CI/CD pipelines, Docker containerization, and AWS services.
